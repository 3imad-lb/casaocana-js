# CasaOcana JS

Application web de gestion quotidienne pour CasaOcana, réalisée en HTML, CSS et JavaScript.

## Fonctionnalités

- Calcul des recettes, des charges et des écarts de caisse.
- Ajout, modification et suppression des lignes de dépenses.
- Gestion des stocks et suivi des ustensiles.
- Mode sombre et impression des tableaux.

## Démarrage

Téléchargez ou clonez ce dépôt, puis ouvrez `index.html` dans votre navigateur.
Aucune installation de dépendances ni compilation n'est nécessaire.

## Structure

- `index.html` : accueil et navigation.
- `calcule.html` : calcul de la journée et gestion des charges.
- `gestionst.html` : gestion des stocks.
- `ustensiles.html` : suivi des ustensiles.
- `style/` : feuilles de style CSS.
- `images/` : images et illustrations.
- `Cahier_des_Charges_CasaOcaca.pdf` : cahier des charges du projet.

Le JavaScript est intégré aux pages HTML. Le projet fonctionne dans le navigateur,
sans serveur applicatif ni base de données. Certaines ressources externes,
notamment les icônes Font Awesome, nécessitent une connexion Internet.
